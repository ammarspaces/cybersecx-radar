# Security Policy

## Supported Versions

THE CYBERSECURITY RADAR is currently under active development.

At this stage, security issues should be reported against the latest version available in the repository.

| Version        | Supported |
| -------------- | --------- |
| Latest         | ✅         |
| Older versions | ❌         |

## Reporting a Security Issue

If you discover a security vulnerability in THE CYBERSECURITY RADAR, please **do not disclose the vulnerability publicly through a GitHub issue**.

Instead, contact the project maintainer privately with:

* A description of the vulnerability
* Steps to reproduce it
* Potential impact
* Relevant logs, screenshots, or proof-of-concept material where appropriate

Please avoid including passwords, API keys, personal information, or other sensitive data in the report.

## Scope

Security reports may include issues such as:

* Arbitrary code execution
* Unsafe file handling
* Path traversal
* Injection vulnerabilities
* Improper handling of untrusted input
* Exposure of sensitive information
* Security issues in the radar engine

Issues related solely to the cybersecurity resources referenced by `resources.json` should generally be reported to the respective resource provider.

## Responsible Disclosure

Please allow reasonable time for the issue to be investigated and, where appropriate, fixed before publicly disclosing the vulnerability.

The project maintainer may acknowledge valid security reports and coordinate disclosure when necessary.

## Important

THE CYBERSECURITY RADAR may reference cybersecurity resources involving malware, exploits, vulnerable applications, offensive security techniques, and other potentially dangerous material.

Users are responsible for ensuring that any investigation or hands-on activity is performed:

* In an authorized environment
* For legitimate purposes
* In accordance with applicable laws and policies

The project itself does not grant authorization to access, attack, or interfere with any third-party system.
